How It Works

This playground demonstrates Chrome's built-in Translation API and Language Detection API, both powered by on-device AI models. All processing happens locally in your browser - no data is sent to external servers.

  • Language Detection: Automatically identifies the language of your input text with confidence scores
  • Translation: Translates between supported language pairs (English ↔ Spanish, English ↔ Japanese)
  • Privacy-First: Everything runs on-device - your text never leaves your browser
  • Real-Time: Language detection happens instantly as you type

📚 What's Happening Under the Hood

1. Language Detection

// Create a language detector
const detector = await LanguageDetector.create();

// Detect the language
const results = await detector.detect(text);
// Returns: [{ detectedLanguage: "es", confidence: 0.95 }, ...]

The API analyzes character patterns, word structures, and linguistic features to identify the language with a confidence score.

2. Translation

// Create a translator for a specific language pair
const translator = await Translator.create({
  sourceLanguage: "es",
  targetLanguage: "en"
});

// Translate the text
const result = await translator.translate(text);
// Returns: "Hello, how are you?"

The Translator API uses neural machine translation models that run entirely in your browser.

🗣️ Supported Language Pairs

Currently, the Translation API supports these pairs:

  • English ↔ Spanish: Full bidirectional translation
  • English ↔ Japanese: Full bidirectional translation

Note: Language Detection works with many more languages, but translation is limited to the pairs above during the preview period.
