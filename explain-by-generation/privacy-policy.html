Privacy Policy for Explain by Generation

Effective Date: September 1, 2025

Extension Name: Explain by Generation

Developer: Ron Dagdag

Introduction

Explain by Generation is a Chrome extension that uses AI to adapt explanations of selected text to different generational communication styles. This privacy policy explains how we handle user data in compliance with Chrome Web Store policies and applicable privacy laws.

Data Collection and Usage

The extension collects and processes the following data:

  • Selected Text: When you highlight text on a webpage and use the extension, the selected text is temporarily processed locally using Chrome's built-in Summarizer API to generate explanations.
  • Tab URL: The URL of the current webpage is used to provide contextual information (e.g., website origin) for more accurate AI explanations. This is not stored long-term.
  • User Preferences: Your selected explanation level (e.g., Gen Alpha, Baby Boomer) is stored locally in Chrome's storage to remember your preference across sessions.

All data processing occurs locally on your device using Chrome's Summarizer API (Gemini Nano). No data is transmitted to external servers, stored in the cloud, or shared with third parties.

Data Retention

Selected text and tab URLs are processed in real-time and not retained after the explanation is generated. User preferences are stored locally on your device until you clear Chrome's storage or uninstall the extension.

Data Sharing and Security

We do not sell, rent, or share any user data with third parties. The extension does not collect personally identifiable information, location data, or any other sensitive data. All AI processing is performed locally, ensuring your data remains private and secure.

Third-Party Services

The extension uses Chrome's built-in Summarizer API, which is provided by Google. This API runs entirely on your device and does not send data to Google or any other external service. For more information, see Google's Privacy Policy.

Children's Privacy

This extension is not intended for children under 13. We do not knowingly collect personal information from children.

Changes to This Policy

We may update this privacy policy as needed. Any changes will be reflected in the extension's documentation and this page.

Contact Us

If you have questions about this privacy policy or the extension, please contact us at ron.dagdag@example.com or through the extension's GitHub repository.

This policy complies with the Chrome Web Store Developer Program Policies and applicable privacy regulations.
